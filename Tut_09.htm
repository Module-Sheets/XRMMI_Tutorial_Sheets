Part 2: Poke Interactible

Buttons Using Poke Interaction

Introduction

The Unity XR Interaction toolkit (and its starter assets) provide 3 components which we will combine to create a functional button which can be activated by the player pushing it with their hand.

·         XR Simple Interactable – Handles events and callbacks

·         XR Poke Filter – Detects collisions from specific directions and passes activation events to an interactable

·         XR Poke Follow Affordance – This is a script from the XRIT Starter Assets which controls visual movement of button when the button is pressed

With these 3 components we will make a button that can be activated by a user pressing it with their hand. The button will then call a function and will move based on where the users' hand is for visual feedback.

Note: this tutorial assumes you have a project with the following packages

·         OpenXR

·         XR Interaction Toolkit

o   Starter Assets

o   XR Device Simulator (optional – needed for working without hardware)

 

Tutorial
Setting Up the Scene

1.      Create a new scene. Go to “File” > “New Scene”

2.      Delete the “Main Camera” that is in the scene

3.      Add a Teleportation Area. Right-click in the Hierarchy, select “XR” > “Teleportation Area”

4.      Add the XR Device Simulator and XR Interaction Setup prefabs. Drag the "XR Interaction Setup" (Assets/XRLab/Prefabs/ XR Interaction Setup.prefab) and "XR Device Simulator" prefabs into your scene

5.      Add a GameObject for the button base. Right-click in the Hierarchy, select "3D Object" > "Cube". This will be the base of our button. Rename it to "ButtonBase".

6.      Add a GameObject for the button cap. Right-click on the "ButtonBase" GameObject, select "3D Object" > "Cube" again. This will be the cap of the button that can be pressed down. Rename it to "ButtonCap".

7.      (Optional) Add a different material to the button cap

Your scene should look like this and should allow you to teleport around the area when running the same
Simple Interactable Component

1.      Select the ButtonCap GameObject in the Hierarchy.

2.      Add the Simple Interactable Component. In the Inspector, click on "Add Component" and search for "Simple Interactable". Select it to add the component to your button.

Poke Filter and Poke Affordance

1.      Add the “Poke Filter” component. In the Inspector, click on "Add Component" and search for "Poke Filter" and add it to your button. The Interactable and Poke Collider fields should automatically be assigned the references

2.      Add the “Poke Affordance” component. Click on "Add Component" again and search for "Poke Affordance". Select it to add the component to your button.

3.      Assign reference to the ButtonCap transform to Poke Affordance component. Drag the transform component of ButtonCap into the “Poke Follow Transform” field.

4.      Set the “Max Distance” field of the poke affordance component to 0.045. You can change this value if you want to the button to move more or less when pressed.

Adding Button Functionality

Callback Implementation

1.      Create a new script. Right-click in the Project window, select "Create" > "C# Script", and give it a name.

2.      Open the script. Double-click on the script to open it

3.      Write a function to activate. Inside the script, Write a public function and add some code inside. In the following example, a print statement is used for testing but this can be any code you want to be activated.

4.      Add script component to button. Go back to Unity, select the "ButtonBase" GameObject, click on "Add Component" in the Inspector, and add the script you just made.

Interactable Event

1.      Select the ButtonCap GameObject in the Hierarchy.

2.      In the Inspector, find the "Simple Interactable" component.

3.      Click on the "+" button next to "On Select" to add a new event

5.      Drag in the instance of your script from the “ButtonBase”

6.      Select the Test function from the dropdown

Testing The Button

1.      Enter Play Mode. Click on the "Play" button in Unity.

2.      Press the button. Use your mouse to click on the button in the scene, or if using VR, move your hand close to the button and poke it.

3.      Check the console. If everything is set up correctly and you used the function from “Callback Implementation” step 3 you should see "The button was pressed" printed in the console when the button is activated.

VR Door Grabbable Tutorial

Introduction

The Unity XR Interaction toolkit has a few components we can combine to create a door we can open in VR by grabbing and pulling/pushing the handle.

·         Hinge Joint – Allows an object to rotate around a given point like a door

·         Fixed joint – This component allows an object to combine its rigidbody with another

·         XR Grab Interactable – This component lets you hold objects and provides callbacks when the hand is near

Note: this tutorial assumes you have a project with the following packages

·         OpenXR

·         XR Interaction Toolkit

o        XR Device Simulator (optional – needed for working without hardware)

o        Starter Assets (optional but recommended)

·         XR Knob, Door and Transform Joint scripts from https://github.com/Unity-Technologies/XR-Interaction-Toolkit-Examples

Tutorial

Setting Up the Scene

1.      Create a new scene. Go to “File” > “New Scene”

2.      Delete the “Main Camera” that is in the scene

3.      Add a Teleportation Area. Right-click in the Hierarchy, select “XR” > “Teleportation Area”

4.      Add the XR Device Simulator and XR Interaction Setup prefabs. Drag the "XR Interaction Setup" (Assets/XRLab/Prefabs/ XR Interaction Setup.prefab) and "XR Device Simulator" prefabs into your scene

5.      Enable or disable the simulator depending on if you’re using VR or Simulated

Setting up the door (Push open)

1.      Add your door model. Drag the door model into the scene. If you do not have one, flattened cube will also work

2.      Add a Hinge Joint Component to the door. On the door object, click “Add Component” and add a Hinge Joint component from the Physics section of the component list (This will automatically add a Rigidbody if there isn’t one)

3.      Add a box collider component to the door if there is not one there already

 

4.      Adjust anchor and axis (optional).  The yellow arrow for the hinge should be at the edge of the door pointing upwards. You can change the position using the “Anchor” and the rotation using the “Axis”. The axis accepts a value between –1 and 1 for each axis

 

5.      Set up Angular Limits. First set the “Use Limits” checkbox to true and click on “Edit Angular Limits”. Then change the angular limits by moving the bounds in the “Scene” window. This will stop the door moving outside of this area  

6.      Initial testing (optional). At this point, the door should open when pushed by an object with a collider however, you can’t grab the handle and open the door at this stage.

 

 

Door Handle

1.      Add an empty transform with a handle as a child on the door. On the model of the door which will move, add an empty transform and add the mesh that will be the handle as a child of that transform

 

2.      Add a collider to the door handle mesh (If there isn’t one already)

3.      Add a Fixed Joint component. Add a fixed Joint to the handle object. It is in the physics section of the component menu

4.      Set the “Connected Body” parameter of the Fixed Joint to the door itself

5.      Add a “Door” script to the parent transform of the door. Add a “Door” script to the “DoorFrame” object and drag the door into the “Door Joint” parameter of the script. This will fill it with the Hinge Joint

6.      Create 2 empties called “HandleInteractable” and “Puller” as a child of door

 

7.      Add a “Transform Joint” script to the Puller

8.      Turn off gravity on the rigidbody on Puller

9.      Add a sphere collider to Puller and make it small enough to fit most of the handle but not overlap with the door frame

10. Set the collider on puller to a trigger

11. On the DoorFrame, Drag the Transform Joint from the Puller into the “Door Puller” field of the “Door” script

12. Add an “XR Knob” script to the Hand Interactable

13. Click the ‘+’ on the colliders and drag in the door handle collider

14. Click the ‘+’ on the “On Value Changed (single)” field and drag in the “DoorFrame” from the hierarchy

15. Set the function to “DoorHandleUpdate”

16.  Expand the “Interactable Events” dropdown at the bottom of the script and find the “Select” section

17. Click the ‘+’ on Select Entered and drag in the DoorFrame into the object slot

18. Assign the function: Door > BeginDoorPulling

19. Click the ‘+’ on Select Exited and drag in the DoorFrame into the object slot

20. Assign the function:  Door > EndDoorPulling

21. Create a new layer and set the door to it. On the door object that opens, create a new layer for doors and assign it to the game object. When the popup asks to change child objects, select “No, this object only”

22. Change the “Pushable” collision matrix to only affect itself. Window > General > Project to open the project settings and in the “Physics” section, find the layer collision matrix and make sure the only tick for your layer is the one with the layer name on the top and side of the matrix

Part 4: Tint and Two-Handed Grabbable

2 Handed Grabbable and Tint Visual

Introduction

The XR Grab interactable has some additional features that allow for grabbing objects with 2 hands in both fixed and dynamic positions. This tutorial details the steps needed to grab an object with 2 hands and will also showcase the simplest way to highlight an object to show the player they can interact with it.

Tutorial

Setting Up the Scene

1.      Create a new scene. Go to “File” > “New Scene”

2.      Delete the “Main Camera” that is in the scene

3.      Add the XR Device Simulator and XR Interaction Setup prefabs. Use the "XR Interaction Setup" (Assets/Samples/XR Interaction Toolkit/3.0.10/Starter Assets/Prefabs/XR Origin (XR Rig) in your scene. This is the prefab we will primarily be editing.

4.      Add a Teleportation Area. Right-click in the Hierarchy, select “XR” > “Teleportation Area”

5.      (Optional) Change the teleportation area material. This may help with seeing movement.

6.      Add an object you want to grab with 2 hands. Drag an asset from the Project browser or create a cube by right clicking the hierarchy and selecting “3D Object > Cube”

7.      Add a collider to your object

8.      Add a grab interactable to your object

Grab Interactable and Tint Visual

Fixed 2 Hand

A fixed 2 handed system forces the user to hold an object in a specific position and rotation. This is done by having 2 transforms that are anchor points which are what the hands will attach to when the grab interactable is activated. Fixed 2 handed controls are best used for objects such as swords and guns which have an intended holding style.

1.      Add 2 empty transforms as a child of your grabbable object

2.      Drag one of the empty transforms into “Attach Transform”. This transform will be the default transform the hand attaches to first

3.      Drag the other transform into “Secondary Attach Transform”. This will be the transform the second hand attaches to

4.      Change “Select Mode” to “Multiple”. This allows multiple interactors to trigger the interaction at the same time

5.      Play the game and test the grabbable object

6.      (optional) Adjust the attach transforms if they don’t align with the hand


 

Dynamic

Dynamic attach changes the location of the attach transform based on where the interactor was at the time the grab interactable was activated. This allows the user to more easily manipulate the object. Dynamic attach works best for small and medium props.

1.      Set “Distance Calculation Mode” to “Collider Volume”

2.      Set “Use Dynamic Attach” to true

Tint Visual

The tint visual component can be used with any interactable component and is triggered by the interactable component itself. It is a simplified version of the Affordance components which are designed to give the player hints for what they can and cannot interact with.

Note: requires a material/shader with Emission support. docs.unity.cn

1.      Add the tint component from “XR > Visual > XR Tint Interactable Visual”

2.      Drag in the Gameobject/mesh renderer you want tinted when the player hovers over
