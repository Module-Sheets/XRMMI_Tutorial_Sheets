VR Animated Hands 

Initial setup 

  1. Import package
  2. Drag in the hand mesh as a child of Left/Right Controller
  1. Click on the hand mesh 
  1. Add a reference to the “HandAnimController” animation into the “Controller” field of the Animator component 
  1. Add the “HandAnimator” script to the hand 
  1. Add an XRRig if there is not one in the scene already 

Setting Per-Hand Input 

Right Hand 

  1. Select the hand model and rotate it –90 degrees on the Z axis

 

  1. Set the hand on the “Hand Animator” component to Right

  1. Click the + on “Grip Action” and “Point Action” and select “Add Binding” 
  1. Double click the grip binding and select “XR Controller > XR Controller (RightHand) > Optional Controls > Grip” 
  1. Double click the point binding and select “XR Controller > XR Controller (RightHand) > Optional Controls > Trigger” 
  1. Save the hand as a prefab 
  1. Drag it into The Right Controller as a child
  2. Settings should look as below:


https://gyazo.com/bd87671fe4a24990578a3c429719c2b8

 

Left Hand 

  1. Select the hand model and rotate it -90 on the Z axis 
  1. Change the scale of the hand model to –1 on the Y axis 
  1. Set the Left/Right hand on the “Hand Animator” component as needed 

  1. Click the + on “Grip Action” and “Point Action” and select “Add Binding” 
  1. Double click the grip binding and select “XR Controller > XR Controller (LeftHand) > Optional Controls > Grip” 
  1. Double click the point binding and select “XR Controller > XR Controller (LeftHand) > Optional Controls > Trigger” 
  1. Save the hand as another prefab 
  2. Drag it into The Right Controller as a child
  3. Settings should look as below:
