Near-Far Interactor

 

 

Introduction 

The near far interactor is a component that combines the direct interactor and the ray interactor together by changing the action based on the distance between the root transform and the interactable object.

Hierarchy Setup 
The standard approach to adding interactors is to have an XR Origin with a camera offset and a hand.

The hand has the Tracked Pose Driver for tracking the controller position and different empty transforms are used for each interactor type.  

 

Using a XR Interaction Group component on the hand object is ideal as it avoids edge cases caused by hierarchy order wherein 2 interactors cancel each other out.  

 

An XR UI Input Module component is needed to allow the near far interactor to work with world space UI.
This must be added by right clicking the hierarchy and navigating to "XR > EventSystem".  
 
Note: There is a second type of eventsystem under "UI > EventSystem". This has different components and will not work on its own.
To use this you will need to manually add the "XR UI Input Module" component and remove the "Input System UI Input Module" as they override each other.
