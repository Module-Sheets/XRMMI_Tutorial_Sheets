CW1 Submission Overview

Follow the full submission process below and test your upload workflow early.

Submission Instructions
  1. Select More Information button in the Assessment link.
  2. Submit files to the SharePoint link below:

    SharePoint link to submit files here:

    https://universityofwestminster.sharepoint.com/:f:/s/00705/IgAZEMZM5mKDSpC7HHkuSbhhAYSiyO7grHNE36dr-Uqqr9s

    • Report (pdf, word format or similar)
    • Unity3D Project(s)
    • Delete the Library Folder of a backed up project to reduce size. Unity rebuilds this.
    • Video demo of CW1 tutorial work and some CW2 planning presentation

    Do not submit just a scene or package file. This will get you a zero mark.

    Use naming convention:

    • XR_2026_CW1_StudentName_StudentNo_UnityProject_1-4.zip (or however organised)
    • XR_2026_CW1_StudentName_StudentNo_UnityProject_5_7.zip (or however organised)
    • XR_2026_CW1_StudentName_StudentNo_Report.pdf (not zipped, actual file)
    • XR_2026_CW1_StudentName_StudentNo_Video.mp4 (or mov, mkv, other formats)

    Do not make nested zips. Zip projects once only and keep multiple projects in their own zip files.

    Do not zip videos or reports.

  3. Submit an official message via the Blackboard submit button:
    • Write I have submitted to SharePoint file link in the text box.
    • Press submit. This gives you an official registry submission and timestamp.

General Information

Electronic submission on Blackboard goes to a SharePoint link with Blackboard confirmation for Registry. The files you upload should be separate Unity Project zip(s), MotionBuilder scene zip(s), and video files. Video links go on the Blackboard sheet. You must submit confirmation via Blackboard for Registry of Submission for their records.

Unlimited uploads are allowed. The last version is marked, so test early to avoid issues and submit files as you have them.

If you have access issues submitting to SharePoint, make sure you are logged into your browser with your university email, and that VPN is on if you are outside the university. Access requests via email cannot be approved. If issues continue, try a new browser, or as a last resort submit to Blackboard.

Test early.

Please use naming convention.
