Grab Interactable Expanded

 for XRIT (XR Interaction Toolkit) is a component that allows an object to be picked up by a player using either an XR Direct Interactor, XR Ray Interactor, or Near-Far Interactor.

Adding the Component

The XR Grab Interactable can be added to any object but needs the following components:

·         A rigidbody component - This will be added automatically if it is missing

·         A collider – This will not be added and can be any of the collider types (box, sphere, mesh etc.)

·         A XR Interaction Manager – This component can be anywhere in the scene and will automatically assign

Useful Parameters

Colliders

The colliders parameter is an array that can take any type of collider. You can also have multiple colliders assigned and can change the number by either pressing the ‘+’ or ‘-’ buttons or directly changing the number of indexes.

Using multiple colliders could be useful if you want a player to grab multiple specific parts of the same object (such as handles) rather than grabbing any part of the object and being able to lift it

 

Movement type

The movement type changes the way the movement from the interactor is transferred to the object and consists of 3 types.

Velocity Tracking

Velocity tracking is the slowest and most realistic of the 3. It takes the velocity and angular velocity from the interactor holding it and adds the force to the hand. It sometimes looks like the object is lagging behind the hand and some fast movements can have unexpected behavior. This movement type is best used for small items that will be placed on other surfaces as it collides with other objects and does not clip into them as easily.

Kinematic Tracking

Kinematic tracking is like velocity tracking, is almost as slow as velocity tracking, and has realistic physics. This mode doesn’t prevent the object from intersecting other rigid bodies though and can have objects forced through other objects. When tracking, the velocity and angular velocity from the interactor and applies it to the kinematic rigidbody specifically.

Instantaneous Tracking

Instantaneous movement is the most responsive of the 3 and works slightly different to the other modes. In this mode the object is moved by setting the position and rotation to the same values as the interactor. This means the object stays attached to the hand with no lagging but lacks some realism. This mode also does not collide with other objects and can easily be placed inside of other objects.

 

 

 

Throwing modifiers

The Grab Interactor also has some physics related parameters that can be used to change how physics is applied to the object when they are released.

Throw On Detach

If the “Throw On Detach” checkbox is enabled, then the velocity of the interactor will be inherited by the object when the interactor is deactivated. If the checkbox isn’t enabled or the rigidbody of the object is kinematic, then all of the other throw related parameters will not be used.

Throw Smoothing Duration

While the object is being held, the velocity and angular velocity are being recorded. The throw smoothing duration defines the period of time the object velocity will be calculated from. The longer this time is the more accurate the velocities will be but with higher values there can occasionally be performance impacts.

Throw Smoothing Curve

This parameter controls the time over which recorded velocities (defined by smoothing duration) are used for velocity calculation. It allows you to specify how much of the recent movement should be used when throwing the object. This helps smooth out the velocity change that occurs when releasing the object at the expense of some responsiveness.

Throw Velocity Scale

This value is the multiplier applied to the velocity the object will inherit when released. Values above 1 will have more force and will move further and faster and values under 1 will have less force applied to them.

Throw Angular Velocity Scale

Like the velocity scale, this value multiplies the angular velocity the object will have when released. Values above 1 will rotate faster and values below 1 will rotate slower when released.

Attach Transforms

The attach transforms allow for changing what part of the model is grabbed and used as an anchor when the user grabs an object. The attach transform can be moved anywhere on the model and can be used for handles or for carefully adjusting a held item, so it has the correct offset.

There are 2 attach transforms on the grab interactable which operate as a primary and secondary grab point. The first attach transform will be used by default and the second attach transform will only activate if 2 interactors are activating the interactable and the select mode is set to “Multiple”.

Gaze configuration

The gaze configuration is a selection of parameters that allow the object to be interacted with by an XR Gaze Interactor component which should be added to the XR Origin. Gaze interaction is like the XR Ray interactor but runs constantly without any visuals and can be used to highlight or select objects.

If the headset supports eye tracking, then the gaze interactor will raycast in the direction the user is looking at. However, if the headset does not have eye tracking support, then the gaze raycast will go towards the forward vector of the headset.

Distance Calculation Mode

The distance calculation mode parameter is a dropdown that allows you to change how the distance calculation for activating the interactable calculated.

These can be useful in specific situations such as when multiple colliders are used, and you want to get information for which collider was used to grab an object.
