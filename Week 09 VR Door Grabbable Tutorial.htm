VR Door Grabbable Tutorial

Introduction

The Unity XR Interaction toolkit has a few components we can combine to create a door we can open in VR by grabbing and pulling/pushing the handle.

·         Hinge Joint – Allows an object to rotate around a given point like a door

·         Fixed joint – This component allows an object to combine its rigidbody with another

·         XR Grab Interactable – This component lets you hold objects and provides callbacks when the hand is near

Note: this tutorial assumes you have a project with the following packages

·         OpenXR

·         XR Interaction Toolkit

o        XR Device Simulator (optional – needed for working without hardware)

o        Starter Assets (optional but recommended)

·         XR Knob, Door and Transform Joint scripts from https://github.com/Unity-Technologies/XR-Interaction-Toolkit-Examples

Tutorial

Setting Up the Scene

1.      Create a new scene. Go to “File” > “New Scene”

2.      Delete the “Main Camera” that is in the scene

3.      Add a Teleportation Area. Right-click in the Hierarchy, select “XR” > “Teleportation Area”

4.      Add the XR Device Simulator and XR Interaction Setup prefabs. Drag the "XR Interaction Setup" (Assets/XRLab/Prefabs/ XR Interaction Setup.prefab) and "XR Device Simulator" prefabs into your scene

5.      Enable or disable the simulator depending on if you’re using VR or Simulated

Setting up the door (Push open)

1.      Add your door model. Drag the door model into the scene. If you do not have one, flattened cube will also work

2.      Add a Hinge Joint Component to the door. On the door object, click “Add Component” and add a Hinge Joint component from the Physics section of the component list (This will automatically add a Rigidbody if there isn’t one)

3.      Add a box collider component to the door if there is not one there already

 

4.      Adjust anchor and axis (optional).  The yellow arrow for the hinge should be at the edge of the door pointing upwards. You can change the position using the “Anchor” and the rotation using the “Axis”. The axis accepts a value between –1 and 1 for each axis

 

5.      Set up Angular Limits. First set the “Use Limits” checkbox to true and click on “Edit Angular Limits”. Then change the angular limits by moving the bounds in the “Scene” window. This will stop the door moving outside of this area  

6.      Initial testing (optional). At this point, the door should open when pushed by an object with a collider however, you can’t grab the handle and open the door at this stage.

 

 

Door Handle

1.      Add an empty transform with a handle as a child on the door. On the model of the door which will move, add an empty transform and add the mesh that will be the handle as a child of that transform

 

2.      Add a collider to the door handle mesh (If there isn’t one already)

3.      Add a Fixed Joint component. Add a fixed Joint to the handle object. It is in the physics section of the component menu

4.      Set the “Connected Body” parameter of the Fixed Joint to the door itself

5.      Add a “Door” script to the parent transform of the door. Add a “Door” script to the “DoorFrame” object and drag the door into the “Door Joint” parameter of the script. This will fill it with the Hinge Joint

6.      Create 2 empties called “HandleInteractable” and “Puller” as a child of door

 

7.      Add a “Transform Joint” script to the Puller

8.      Turn off gravity on the rigidbody on Puller

9.      Add a sphere collider to Puller and make it small enough to fit most of the handle but not overlap with the door frame

10. Set the collider on puller to a trigger

11. On the DoorFrame, Drag the Transform Joint from the Puller into the “Door Puller” field of the “Door” script

12. Add an “XR Knob” script to the Hand Interactable

13. Click the ‘+’ on the colliders and drag in the door handle collider

14. Click the ‘+’ on the “On Value Changed (single)” field and drag in the “DoorFrame” from the hierarchy

15. Set the function to “DoorHandleUpdate”

16.  Expand the “Interactable Events” dropdown at the bottom of the script and find the “Select” section

17. Click the ‘+’ on Select Entered and drag in the DoorFrame into the object slot

18. Assign the function: Door > BeginDoorPulling

19. Click the ‘+’ on Select Exited and drag in the DoorFrame into the object slot

20. Assign the function:  Door > EndDoorPulling

21. Create a new layer and set the door to it. On the door object that opens, create a new layer for doors and assign it to the game object. When the popup asks to change child objects, select “No, this object only”

22. Change the “Pushable” collision matrix to only affect itself. Window > General > Project to open the project settings and in the “Physics” section, find the layer collision matrix and make sure the only tick for your layer is the one with the layer name on the top and side of the matrix
