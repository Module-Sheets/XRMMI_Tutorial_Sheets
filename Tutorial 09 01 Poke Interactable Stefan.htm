Buttons Using Poke Interaction

Introduction

The Unity XR Interaction toolkit (and its starter assets) provide 3 components which we will combine to create a functional button which can be activated by the player pushing it with their hand.

·         XR Simple Interactable – Handles events and callbacks

·         XR Poke Filter – Detects collisions from specific directions and passes activation events to an interactable

·         XR Poke Follow Affordance – This is a script from the XRIT Starter Assets which controls visual movement of button when the button is pressed

With these 3 components we will make a button that can be activated by a user pressing it with their hand. The button will then call a function and will move based on where the users' hand is for visual feedback.

Note: this tutorial assumes you have a project with the following packages

·         OpenXR

·         XR Interaction Toolkit

o   Starter Assets

o   XR Device Simulator (optional – needed for working without hardware)

 

Tutorial
Setting Up the Scene

1.      Create a new scene. Go to “File” > “New Scene”

2.      Delete the “Main Camera” that is in the scene

3.      Add a Teleportation Area. Right-click in the Hierarchy, select “XR” > “Teleportation Area”

4.      Add the XR Device Simulator and XR Interaction Setup prefabs. Drag the "XR Interaction Setup" (Assets/XRLab/Prefabs/ XR Interaction Setup.prefab) and "XR Device Simulator" prefabs into your scene

5.      Add a GameObject for the button base. Right-click in the Hierarchy, select "3D Object" > "Cube". This will be the base of our button. Rename it to "ButtonBase".

6.      Add a GameObject for the button cap. Right-click on the "ButtonBase" GameObject, select "3D Object" > "Cube" again. This will be the cap of the button that can be pressed down. Rename it to "ButtonCap".

7.      (Optional) Add a different material to the button cap

Your scene should look like this and should allow you to teleport around the area when running the same
Simple Interactable Component

1.      Select the ButtonCap GameObject in the Hierarchy.

2.      Add the Simple Interactable Component. In the Inspector, click on "Add Component" and search for "Simple Interactable". Select it to add the component to your button.

Poke Filter and Poke Affordance

1.      Add the “Poke Filter” component. In the Inspector, click on "Add Component" and search for "Poke Filter" and add it to your button. The Interactable and Poke Collider fields should automatically be assigned the references

2.      Add the “Poke Affordance” component. Click on "Add Component" again and search for "Poke Affordance". Select it to add the component to your button.

3.      Assign reference to the ButtonCap transform to Poke Affordance component. Drag the transform component of ButtonCap into the “Poke Follow Transform” field.

4.      Set the “Max Distance” field of the poke affordance component to 0.045. You can change this value if you want to the button to move more or less when pressed.

Adding Button Functionality

Callback Implementation

1.      Create a new script. Right-click in the Project window, select "Create" > "C# Script", and give it a name.

2.      Open the script. Double-click on the script to open it

3.      Write a function to activate. Inside the script, Write a public function and add some code inside. In the following example, a print statement is used for testing but this can be any code you want to be activated.

4.      Add script component to button. Go back to Unity, select the "ButtonBase" GameObject, click on "Add Component" in the Inspector, and add the script you just made.

Interactable Event

1.      Select the ButtonCap GameObject in the Hierarchy.

2.      In the Inspector, find the "Simple Interactable" component.

3.      Click on the "+" button next to "On Select" to add a new event

5.      Drag in the instance of your script from the “ButtonBase”

6.      Select the Test function from the dropdown

Testing The Button

1.      Enter Play Mode. Click on the "Play" button in Unity.

2.      Press the button. Use your mouse to click on the button in the scene, or if using VR, move your hand close to the button and poke it.

3.      Check the console. If everything is set up correctly and you used the function from “Callback Implementation” step 3 you should see "The button was pressed" printed in the console when the button is activated.
