2 Handed Grabbable and Tint Visual

Introduction

The XR Grab interactable has some additional features that allow for grabbing objects with 2 hands in both fixed and dynamic positions. This tutorial details the steps needed to grab an object with 2 hands and will also showcase the simplest way to highlight an object to show the player they can interact with it.

Tutorial

Setting Up the Scene

1.      Create a new scene. Go to “File” > “New Scene”

2.      Delete the “Main Camera” that is in the scene

3.      Add the XR Device Simulator and XR Interaction Setup prefabs. Drag the "XR Interaction Setup" (Assets/Samples/XR Interaction Toolkit/2.4.3/Starter Assets/ XR Interaction Setup.prefab) and "XR Device Simulator" prefabs into your scene. This is the prefab we will primarily be editing.

4.      Add a Teleportation Area. Right-click in the Hierarchy, select “XR” > “Teleportation Area”

5.      (Optional) Change the teleportation area material. This may help with seeing movement.

6.      Add an object you want to grab with 2 hands. Drag an asset from the Project browser or create a cube by right clicking the hierarchy and selecting “3D Object > Cube”

7.      Add a collider to your object

8.      Add a grab interactable to your object

Grab Interactable and Tint Visual

Fixed 2 Hand

A fixed 2 handed system forces the user to hold an object in a specific position and rotation. This is done by having 2 transforms that are anchor points which are what the hands will attach to when the grab interactable is activated. Fixed 2 handed controls are best used for objects such as swords and guns which have an intended holding style.

1.      Add 2 empty transforms as a child of your grabbable object

2.      Drag one of the empty transforms into “Attach Transform”. This transform will be the default transform the hand attaches to first

3.      Drag the other transform into “Secondary Attach Transform”. This will be the transform the second hand attaches to

4.      Change “Select Mode” to “Multiple”. This allows multiple interactors to trigger the interaction at the same time

5.      Play the game and test the grabbable object

6.      (optional) Adjust the attach transforms if they don’t align with the hand


 

Dynamic

Dynamic attach changes the location of the attach transform based on where the interactor was at the time the grab interactable was activated. This allows the user to more easily manipulate the object. Dynamic attach works best for small and medium props.

1.      Set “Distance Calculation Mode” to “Collider Volume”

2.      Set “Use Dynamic Attach” to true

Tint Visual

The tint visual component can be used with any interactable component and is triggered by the interactable component itself. It is a simplified version of the Affordance components which are designed to give the player hints for what they can and cannot interact with.

1.      Add the tint component from “XR > Visual > XR Tint Interactable Visual”

2.      Drag in the Gameobject/mesh renderer you want tinted when the player hovers over
