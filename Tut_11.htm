Tutorial 11: Locomotion

Target versions: Unity 6000.0.58f2, URP, XR Interaction Toolkit (XRIT) 3.0.10, OpenXR, and XR Device Simulator.

Overview

This tutorial has two practical parts:

  1. Customizing XR Locomotion (disable locomotion systems and rebind controls)
  2. Lazy Navigation UI (World Space UI that follows the player using Lazy Follow)

Reference hierarchy: XR Interaction Setup > XR Origin (XR Rig) > Locomotion

Part 1: Customizing XR Locomotion

Introduction

The XR Interaction Toolkit Starter Assets include multiple locomotion methods by default. In this part, you will disable unneeded methods and rebind inputs.

Prerequisites

  • OpenXR package installed.
  • XR Interaction Toolkit 3.0.10 installed.
  • Starter Assets sample imported.
  • XR Device Simulator (optional, but recommended for keyboard and mouse testing).

Scene setup

  1. Create a new scene (File > New Scene).
  2. Delete the default Main Camera.
  3. Add XR Interaction Setup to the Hierarchy.
  4. Add XR Device Simulator if needed.
  5. Add a teleport surface: right-click Hierarchy > XR > Teleportation Area.

Disable a locomotion provider

  1. Expand XR Interaction Setup > XR Origin (XR Rig) > Locomotion.
  2. Locate provider objects such as Move, Turn, Teleportation, Climb, and Grab Move.
  3. Disable any provider GameObject you do not want.
  4. Press Play and verify that locomotion behavior is removed.
Troubleshooting: If disabled locomotion still works, check for duplicate rigs or duplicate locomotion providers in the scene.

Hierarchy search helper (t:)

Use Hierarchy search with component type filters to find locomotion-related providers:

t:SnapTurnProvider

t:ContinuousTurnProvider

t:DynamicMoveProvider

t:TeleportationProvider

t:GrabMoveProvider

t:TwoHandedGrabMoveProvider

t:ClimbProvider

Rebind locomotion controls

  1. Open the Input Actions asset used by XR Interaction Setup.
  2. Find locomotion action maps for left and right controller input.
  3. Edit actions such as Move, Turn, Teleport Mode Activate, and Teleport Mode Cancel.
  4. Configure bindings for controller input and simulator keyboard input.
  5. Save the Input Actions asset and test in Play Mode.

Part 2: Lazy Navigation UI (World Space)

Introduction

In VR, avoid Screen Space - Overlay interfaces. Use a World Space canvas and make it follow the headset with smooth, delayed movement using Lazy Follow.

A) Canvas setup (World Space)
  1. Create Canvas (Hierarchy > Create > UI > Canvas).
  2. Add UI elements (Text, Buttons, Images) as needed.
  3. Create a dedicated UI layer (for example: VR_UI).
  4. Assign the Canvas and children to VR_UI layer.
  5. Set Canvas Render Mode to World Space.

B) Lazy Follow setup
  1. Add Lazy Follow component to the Canvas object.
  2. Set Target to the XR camera under XR Origin.
  3. Set Target Offset to (0, 0, 2).
  4. Set Position mode to Follow.
  5. Set Rotation mode to Look At.
  6. Tune movement and smoothing values for comfort.

C) URP camera stacking for UI overlay
  1. On XR Main Camera (Base), disable VR_UI in Culling Mask.
  2. Create a UI Camera and set Render Type to Overlay.
  3. Set UI Camera Culling Mask to only VR_UI.
  4. Add UI Camera to Base camera Camera Stack.
  5. Press Play and confirm UI visibility and smooth following.
If Camera Stack is missing: verify your URP renderer configuration supports camera stacking.
