Aniimation 04: Unity Project - Animation Simple Interactor

 

1.       Unity Animation of Lego Brick

a.       Import Lego Brick and add narrative animation

                                                               i.      Create Plane, place at 0,0,0, and scale to 10,1,5

                                                             ii.      Import a single lego brick and duplicate it twice, rename to brick 01, 02, 03

                                                           iii.      Duplicate and replace materials to be R,G,B

                                                           iv.      Position with snapping (hold CTRL) https://learn.unity.com/tutorial/unity-tips#5c7f8528edbc2a002053b473

                                                             v.      Select Brick 01

                                                           vi.      Open Window, Animation from top menu

                                                          vii.      Create Animator/Animation, name as AnimX.anim

                                                        viii.      Add Property: Transform/Position

                                                            ix.      Turn on record button

                                                             x.       See the start key

                                                            xi.      Drag transport  to 0:30,

                                                          xii.      With Translate gimbal selected (“w” key), drag brick in X axis, See the new key made by recording. Turn off recording mode

                                                        xiii.      Start keyframe of position.x at 0:00 – copy

                                                        xiv.      Drag transport  to 1:00, paste position.x key here

                                                          xv.      Drag transport bar back and forth to check animation.

                                                        xvi.      Open Assets Folder and Inspector to see Animator Controller

                                                       xvii.      Open Animator Window to see State machine and Animation

                                                     xviii.      Press play button to view narrative animation created in Unity!

                                                        xix.      Repeat for other bricks in Y and Z axes, try without recording.

b.       Program input key to trigger Unity Animations

                                                               i.      Create New Script for Lego Brick 01 – call Animator Trigger

                                                             ii.      With Lego Brick 01 selected:

                                                           iii.      Create New Animation in Animation Window – name Rest

                                                           iv.      This should be at the start position and not move

                                                             v.      Drag the Rest animation into the Animator window for Lego Brick 01

                                                           vi.      Right click to make default state (Entry)

                                                          vii.      Delete transition to AnimX, connect to Any State

                                                        viii.      Make transition to Exit State

                                                            ix.      Use key input code to trigger and play AnimX

                                                             x.      Add a Box collider and select trigger box

                                                            xi.      Use  mousedown code to trigger and play AnimX

                                                          xii.      Repeat for other bricks

2.       3DS Max (fbx) Animation Import – Lego Brick Array

a.       Import brick with multiple animations – array

b.       Divide into resting, explode, and implode animations

                                                               i.      This is done in by selecting whole array model in project window

                                                             ii.      In Inspector window, view Animation tab

c.       Setup animator controller and explode, implode off of entry

                                                               i.      Right click in project to create animator controller

                                                             ii.      In top window menu, open Animator window

d.       Create bricks to trigger explode and implode

e.       Put script on explode brick to access the explode by public GO variable

f.        Put script on implode brick to access the implode by FindObject.GetComponent.Script

g.       This relies on Animator States to control the exploded, imploded states

 

Alternate scripted version: Have Boolean to check for exploded, imploded state (all is internal on brick array script)

 

3.       Try the same with the Lego Minifigure

a.       Import Lego Minifigs into Unity or start with the 1st Unity Project with them imported

b.       Create animations for Minifigs with Animation window as above

c.       Create Animator for Minifigs with Animator as above

d.       Download and study the 2nd Unity project

g.       Use Animator.enable for the Cubes

Script - Trigger Animations in Animator

AnimatorTrigger

using System.Collections;

using System.Collections.Generic;

using UnityEngine;

 

public class AnimatorTrigger : MonoBehaviour

{

       // Start is called before the first frame update

       void Start()

       {

 

       }

 

       // Update is called once per frame

       void Update()

       {

              if (Input.GetKeyDown("1"))

              {

                     this.GetComponent<Animator>().Play("AnimX");

              }

 

       }

 

       void OnMouseDown()

       {

              this.GetComponent<Animator>().Play("AnimX");

       }

 

}
